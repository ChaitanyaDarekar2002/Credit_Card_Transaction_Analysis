# Credit Card Transactions & Customer Analysis

## Project Overview

Developed an interactive **Credit Card Transactions & Customer Analysis dashboard** using **Python, SQL, Power BI, and DAX** to analyze transaction performance, customer behavior, spending patterns, and card usage.

The project contains two Power BI dashboard pages: **Credit Card Transactions** and **Credit Card Customer**, providing both financial and customer-level insights.

## Tools & Technologies

* Python
* Pandas
* NumPy
* SQL
* Power BI
* DAX
* Data Visualization

## Data Analysis

### Python

* Loaded and explored customer and credit card transaction datasets using Pandas.
* Performed data cleaning and preprocessing.
* Checked data types, missing values, and duplicate records.
* Conducted exploratory data analysis to understand customer and transaction patterns.
* Prepared cleaned data for SQL analysis and Power BI reporting.

### SQL

Used SQL for data extraction, transformation, aggregation, and business analysis.

Key analysis included:

* Total transaction amount
* Transaction count
* Interest earned
* Annual fees
* Customer income
* Spending by card category
* Spending by expenditure type
* Customer job and education analysis
* Transaction trends by quarter and week
* Card usage analysis

## Key Business Insights

* **Swipe transactions** generated the highest transaction amount compared with Chip and Online transactions.
* **Bills** represented one of the largest expenditure categories.
* **Businessman customers** generated the highest transaction amount among the customer job categories shown.
* **Graduate customers** contributed the highest transaction amount among education categories.
* **Blue card customers** generated the largest transaction amount among card categories.
* Quarterly analysis was used to compare transaction revenue and transaction volume.
* Customer segmentation by age, gender, education, occupation, marital status, and dependents helped identify differences in spending behavior.

## Project Outcome

Built a two-page interactive Power BI dashboard that transforms raw credit card and customer data into actionable business insights. The project demonstrates an end-to-end data analytics workflow:

**Python → Data Cleaning & EDA → SQL → Data Analysis → Power BI → DAX → Interactive Dashboard**
